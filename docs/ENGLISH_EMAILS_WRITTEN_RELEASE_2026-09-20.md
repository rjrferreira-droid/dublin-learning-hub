# English sequence 4: written release

This release prepares the existing authored email lesson for the isolated V2
catalogue while new real-voice acceptance is pending. It does not activate
Professor or Premium Audio for this lesson.

The lesson has four sections, three local practice exercises, a worked approval
request, five checkpoint questions and six terms. The invoice, date, deadline and
people are fictional. A transfer task applies the same skill to an everyday class
enquiry, preserving the distinction between availability and a confirmed booking.
Valid regional wording is accepted. Local answers do not establish saved mastery.

The operational case, deadline wording, non-blaming follow-up, factual checks and
everyday transfer are original teaching examples. The source series is labelled
A2/B1; it supports foundation language, not a claim that this lesson certifies B2
or C1 proficiency. There is no source-text or audio reproduction.
