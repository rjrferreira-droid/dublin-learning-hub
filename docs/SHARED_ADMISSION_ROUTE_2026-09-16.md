# Hosted admission wiring with shared encrypted preflights

The new /api/professor-admission route connects fresh learner Auth, server-owned reference minting, shared encrypted storage and bound atomic start. It is restricted to the exact feature Preview and approved V2 URL and defaults CLOSED. Explicit PROFESSOR_ADMISSION_STAGE=shared-preview-validation-v1, server-only SUPABASE_SERVICE_ROLE_KEY and a 32-byte hex PROFESSOR_PREFLIGHT_KEY are required. No values were provisioned or changed. The existing readiness UI does not call this route yet.

The shared store uses two service-only RPCs and a private RLS-enabled table. No API role can read/write that table directly. Put is insert-only with unique reference and user/request; consume commits an atomic conditional UPDATE before returning ciphertext. Owner/request mismatch, expiry or consumed rows return no envelope. Lost replies, decryption failures and process restarts never reclaim consumption. Existing AES-GCM binds scope and four-minute lifetime; no bearer token is persisted. The route rechecks Auth before consuming and again before bound admission. Strict bodies reject drafts, owner/callback overposting and unexpected fields. Only public receipt/acknowledgement is returned.

A positive validation admission reserves budget; it is NOT free merely because no provider follows. This route has no LiveKit/token/dispatch/model/TTS capability. It does not activate paid sessions, publish P1 or resolve uncertain existing holds. Starting stays closed until connected prerequisites and configuration are reviewed. Dispatch assembly and durable dispatch fence remain separate work; do not claim complete voice integration.

SQL is an additive candidate after written-professor-binding.sql, installed only in disposable CI. Neither that binding nor this shared store was installed in connected V2 by this change. Do not install the empty foundation on populated V2. The original POSIX/local route rehearsal is retained for its existing tests; hosted wiring uses only the shared store.

Local tests: 575 contracts plus one endpoint gate test passed, build/API typecheck passed. Shared-store unit tests cover ciphertext-only persistence, lost/missing/corrupt reply with no retry, fresh Auth and strict inputs. Actual platform CI issues through the new route in one process, terminates it, and races two fresh-authenticated processes through SQL consumption and real zero-budget atomic start. It also checks anon/authenticated denial, wrong-owner/request refusal and blocked third-process replay, followed by zero sessions/holds/usage. CI results belong to the final feature commit.

No connected database write, paid provider call, worker deployment or main promotion. Remaining activation dependencies: incremental V2 reference/shared-store installation, private key/service configuration, session UI acknowledgement/recovery wiring, and authenticated hosted acceptance. P1 remains unpublished.
