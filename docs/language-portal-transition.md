# Language Hub: active course boundary

The active portal serves Rafael and Viviane with English and Spanish. English is
the default for both accounts. Their identity and existing study history remain
unchanged. English's everyday/technical balance remains 50/50 for Rafael and
80/20 for Viviane. Spanish content has not been authored yet; its visible course
page is a truthful preparation state, with no fabricated lesson or assessment.

Each language unit follows the same structure: optional topical video, Learn,
Audio, Practice, Speaking, Professor, optional complementary audio. The amount
of teaching and the number of listening questions follow the actual grammar
concepts. Practice combines objective and written responses; Speaking focuses
on pronunciation. Source references stay editorial rather than a learner tab.

ACCA and Payroll are outside the active catalogue, course tree, default route,
revision queue and aggregated learning panel. Their source modules, database
rows and learner progress remain preserved for a later project. No migration or
destructive deletion is part of this change. Old aggregate competencies, errors
and reviews cannot be assigned reliably to a language, so they are not surfaced
as English evidence. English session history is filtered by known lesson IDs.

Content publication is a separate step. English now uses the five-stage tab
layout, while some existing units still carry legacy activity counts and feedback
inside those tabs. They need the next content/assessment pass. Spanish must receive its own
unit catalogue and language-specific audio, questions, feedback and persistence
before it can be marked active. Never reuse English assessment data as Spanish.
