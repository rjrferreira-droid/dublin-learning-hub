## Target and honest baseline

The target is eight lessons per active track (16 total), including the two existing reference lessons, not 16 additional lessons. The roadmap remains a draft, not proof of publication or acceptance. Existing drafts must pass review; authored files do not count as completed learner journeys. Payroll's eight-lesson roadmap is retained for a later phase and excluded from this release denominator.

| Premium Audio | Approved lesson generates once, cached replay does not regenerate, failed/uncertain attempts recover safely, mobile playback verified | Runtime remains closed; provider configuration and reviewed lesson publication remain prerequisites |
| Finished experience | Phone and desktop navigation, loading/empty/error states, readable content, accessibility and sign-out/account switch pass checks | Automated checks do not replace real-device acceptance |

Complete means every applicable gate passes with dated evidence, not merely that the interface or a draft exists. Track implementation, publication and live acceptance separately. Do not derive a completion percentage from file counts or reduce the denominator silently.
